# Wolfie OS — Emergency Triage Rules

## 1. Red-Flag Emergencies

### Gastric Dilatation-Volvulus (GDV / Bloat)
- If a dog has a distended, tight abdomen, non-productive retching, restlessness, pale gums, repeated drooling, or weakness, treat the situation as an emergency.
- Immediate veterinary evaluation is required if the abdomen is visibly swollen and the pet is pacing or appears in distress.
- Bloat is a high-priority event and must be moved to the front of any scheduling queue.

### Lily Toxicity in Cats
- If a cat has eaten any lily, including common household lily varieties, immediately contact a veterinarian even if the pet appears normal at first.
- Kidney injury can progress quickly despite a delayed outward appearance of symptoms.
- Lily exposure must bypass routine medication scheduling and be escalated to urgent triage.

### Male Cat Urinary Obstruction
- Male cats that strain to urinate, repeatedly visit the litter box without producing urine, or show vocalization, licking the genitals, or lethargy need emergency attention.
- This pattern is a high-priority veterinary event and should bypass routine scheduling.

## 2. First-Aid Time-Boxing
- Perform a 30-minute gum color check if there is concern about perfusion, shock, or collapse.
- Monitor respiration rate continuously and record it at the start of any emergency evaluation.
- Any abnormal respiratory pattern or gum color change should trigger a rapid escalation to veterinary guidance.

## 3. OTC Dosage Safety Upper Bounds
- Never exceed the weight-based OTC upper bound for any medication unless a veterinarian explicitly directs a different dose.
- Use only the bottle label or prescriber dosing for the actual pet weight; do not extrapolate upward from human dosage assumptions.
- If an OTC medication label is unclear or a pet is below the recommended minimum weight threshold, do not self-dose beyond the label's safe range.
- All medication dosing and timeline recommendations must remain within the verified weight-based safe window.
